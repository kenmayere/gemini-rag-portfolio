### Exploring Text Embeddings and RAG with Google Gemini
This repository documents my hands-on exploration of text embeddings using Google's Gemini embedding model and Python. To explore this, I started experimenting with converting text strings into numerical vector representations (embeddings). This provides an introduction to how modern AI systems represent and compare textual information.
The longer-term objective is to build on this foundation by exploring document ingestion, embedding generation and semantic retrieval as building blocks for Retrieval-Augmented Generation (RAG).

This is an independent learning project documenting my progress and practical experimentation with Generative AI concepts.

#### Project Objectives
 - Practical understanding of text embeddings and their role in representing textual information numerically.
 - Gain insights into how models transform text into vector representations
 - Semantic simialarity and how vector representations can be used to identify related pieaces of text

#### Project Progress (This is a live repo)
##### Stage 1: Exploring Text Embeddings
The initial phase focuses on understanding how text strings are converted into numerical embeddings using Google's Gemini embedding model.
The experiments provide an opportunity to explore how textual information can be represented as vectors and how these representations can support semantic comparison and retrieval.

##### Stage 2: Document Ingestion and Semantic Retrieval (Planned)
The next stage will extend the initial experiments beyond individual text strings to uploaded documents.
    The intended workflow includes:
    1.	Uploading and extracting text from documents.
    2.	Splitting documents into smaller, manageable text segments (chunking).
    3.	Generating embeddings for the extracted text.
    4.	Comparing vector representations to identify semantically relevant content.
    5.	Retrieving relevant document segments in response to a query.

##### Stage 3: Exploring Retrieval-Augmented Generation (Planned)
Building on document retrieval, I intend to explore how retrieved information can be provided as context to a generative AI model to support more relevant, context-grounded responses
